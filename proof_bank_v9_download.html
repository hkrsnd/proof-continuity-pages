Schema

Each line is a JSON object with the following fields:

FieldTypeDescription
idstringUnique example identifier
system_promptstringSystem message with format instructions
user_promptstringUser message with context + question
completionstringGold reasoning trace (SFT only; null in GRPO)
expected_answerstringGround-truth answer
domainstringReasoning domain (logic)
logic_typestringpropositional, first_order, or non_monotonic
logic_subtypestringSpecific inference rule (e.g., modus_ponens)
theorystringTheory name for LogicBench examples
datasetstringSource dataset identifier
contextstringNatural language premises
questionstringNatural language question
factslistParsed logical facts
implicationslistParsed logical rules/implications
disjunctionslistParsed disjunctions
default_ruleslistDefault rules (non-monotonic logic)
query_literalstringFormal query to prove/refute
inference_planlistExpected inference steps
sourcestringData source (GRPO only)
