Bugs Found

Bug 1 (Critical): 57% of data missing <think> template

The 5 new v10 datasets (nl_prontoqa, folio_style, synthetic_relational, owa_unknown, binary_no_training) had user prompts ending with just the question:

Is the following statement true or false? Quinn is heavy. ↓ Model doesn't know to produce <step> tags → format_reward = -1.0

Working v9 data always ended with:

Answer by thinking through the problem and recording formal steps: <think> [Your reasoning here, with <step> tags for each key deduction] </think> Answer: ___________

Impact: 57% of training batches produced format_reward = -1.0. The model was pulled in opposite directions — 43% rewarding structured reasoning, 57% punishing it. This caused the format collapse seen in logs (0.88 → -1.0).

Bug 2 (High): Answer-type misclassification on 23% of data

The 5 new dataset names were not in the answer_type dispatch table (train_experiment.py:595-616). All fell through to "binary".

Bug 3 (High): Multi-node colocate — IS ratio collapse

TRL's GRPOTrainer multiplies loss by an importance sampling ratio:

IS_ratio = exp(Σ (old_logp - sampling_logp)) loss = per_token_loss × IS_ratio

In colocate mode with load_in_4bit: true:

  • Training model: HuggingFace BitsAndBytes NF4
  • Colocated vLLM: vLLM's own BnB implementation
  • Per-token logprob difference: ~0.5 nats (different quantization implementations)
  • Over ~1000 tokens: exp(-500) ≈ 0
  • Loss × 0 = 0 → no gradients, model never updates
